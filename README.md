# Jah Creative

Marketing site for Jah Creative (jahcreative.co).

## Stack

Vite 6 · React 19 · TypeScript · Tailwind v4 · lucide-react · motion — same
setup as the LX Auto, Rustic Steel and S.W.A.G builds. Deployed on Netlify
(`netlify.toml`).

## Commands

```
npm run dev      # dev server on :3000
npm run build    # production build to dist/
npm run preview  # serve the production build
npm run lint     # tsc --noEmit
```

## Content

All copy and contact details live in `src/data.ts`. Brand colours and fonts are
defined in the `@theme` block of `src/index.css`.
